🚀 BotTask

Transforme suas tarefas em missões e evolua sua produtividade!

O BotTask é uma aplicação web de gerenciamento de tarefas com elementos de gamificação. Seu objetivo é tornar a organização diária mais divertida, utilizando 
um sistema de XP, níveis e conquistas.

🎯 Sobre o projeto

O BotTask foi desenvolvido como um projeto de estudo em desenvolvimento web, buscando integrar funcionalidades de gerenciamento de tarefas com uma experiência interativa
e moderna.

✨ Funcionalidades

📝 Cadastro de tarefas e missões

✅ Conclusão de tarefas

⭐ Sistema de experiência (XP)

🎮 Sistema de níveis

🏆 Sistema de conquistas

👤 Perfil personalizado

🌙 Interface moderna com tema escuro

☁️ Aplicação hospedada na internet

🛠️ Tecnologias utilizadas

Python

Flask

HTML5

CSS3

PostgreSQL

Git
